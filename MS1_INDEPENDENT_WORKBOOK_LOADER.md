# MS-1 Acceptance — Independent Workbook Loader

- Load an existing Progress workbook directly from the Amount Mapping tab.
- Load an existing BOQ workbook independently.
- List all BOQ worksheets without auto-detection.
- Load only the worksheet selected by the user.
- Validate required Progress and BOQ columns.
- Stream workbook rows into the in-memory mapping store and close the workbook.
- Show loaded file paths and row counts.
- Enable export only when both Progress activities and BOQ items are available.
- Existing XML generation can still pass its newly created Progress workbook into Amount Mapping.
