PRESERVATION DESIGN
Finance extension does not rebuild existing Progress/Dashboard/Payment/EV views.
It grafts only owned sheets/tables into the original package, preserving existing
chart/drawing bytes and original calculation properties. Styles are remapped
without changing original style indices. The existing numbered opaque-part
restoration helper could not guarantee this boundary, so a finance-only adapter
was necessary. No general-purpose replacement infrastructure was introduced.
Mapping follows Payment's edited-source precedence; the new lifecycle tests
exercise all four Progress/Payment rebuild variants plus Mapping.
Historical FF-0 tests were updated only for the now-registered visibility titles
and explicit rejection of the disposable probe schema by production Mapping.
