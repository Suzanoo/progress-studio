# Historical Documentation

This directory preserves design, milestone, acceptance and legacy user-guide records for traceability.

Historical files explain decisions made at a particular point in the project. They do not override current product contracts.

Use these active sources instead:

1. `README.md` — product overview and workflow.
2. `ARCHITECTURE.md` — architecture/ownership source of truth.
3. `docs/USER_WORKFLOW.md` — current user workflow.
4. `docs/DEVELOPMENT.md` — development rules.
5. `docs/TESTING.md` — test strategy.
6. `ROADMAP.md` — current pre-production roadmap.

Git history remains the authoritative record for deleted/renamed historical files.
