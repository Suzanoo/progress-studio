# MS-6.2 — Main Amount Contract and Mapping Stabilization

## Purpose

Correct the MS-6 export target and validate the generated Progress workbook before mapping begins.

## Workbook contract

A valid Progress workbook must contain:

- worksheet `main`
- worksheet `Amount Mapping`
- required `main` headers: `Row Type`, `Activity ID`, `P/A`, `Outline Level`, `Amount`

The application does not guess renamed worksheet names. A missing `main` worksheet produces a direct instruction to rename it back.

## Export contract

- `MappingStore` remains the runtime source of truth.
- Allocated BOQ amounts are aggregated by Activity ID.
- Plan Activity Amount is written to matching Activity rows in `main`.
- Actual-row Amount remains blank.
- WBS and Project Summary Amount cells are regenerated as descendant-Activity formulas.
- `Amount Mapping` is synchronized for visibility and compatibility, but it is not the workbook source of truth.
- `progress` and `progress_table` remain downstream formula-driven worksheets.
- Export requests full recalculation when Excel opens the workbook.
- The Activity Amount total written to `main` must match allocated BOQ money within one cent.

## GUI stabilization

Both Mapping tables use a visible native vertical scrollbar. Mouse-wheel scrolling applies only to the table under the pointer.
