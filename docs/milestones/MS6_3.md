# MS-6.3 — Excel Recalculation Contract

## Goal

Ensure Microsoft Excel recalculates every formula that depends on Activity Amount after a mapped workbook is exported.

## Completed

- Updated Activity Amount only in the generated `main` worksheet.
- Set calculation mode to Automatic.
- Requested full calculation and forced calculation when Excel opens the export.
- Reset the Excel calculation engine ID to `0` so stale cached values are not trusted.
- Added package-level tests confirming that no stale `calcChain.xml` remains.
- Removed the embedded S-Curve preview and its unused service from the current desktop scope.
- Preserved lightweight, event-driven Treeview behavior with no hover tooltips or animation.

## Percentage behavior

- Activity weekly percentages remain user-entered distribution values and are not changed by Amount mapping.
- WBS and Project Summary weekly percentages are amount-weighted Excel formulas and recalculate after the exported workbook opens in Microsoft Excel.
- `progress` and `progress_table` continue to derive their results from `main`.
